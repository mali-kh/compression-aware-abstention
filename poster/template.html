Teaching LLMs to refuse when KV-compression masks remove answer evidence

1Compression removes evidence. Models don’t notice.

KV compressors (KVzip, SnapKV, Expected Attention) evict context tokens to save memory. When the evicted tokens carry the answer evidence, the remaining context is still fluent and on-topic, but no longer determines the answer, and the model fabricates one.

2Label by evidence survival, then train

{{METHOD_DIAGRAM}}
1

Tight-span localization. MuSiQue 2-hop decompositions give each sub-answer as a short string; we locate it verbatim in its supporting paragraph (median 3 tokens). Paragraph-level spans (~100 tokens) average out under compression and give zero label variance.

2

Label from the mask. Run a compressor at retention r ∈ {0.05 … 0.80}. CONFIDENT if every span keeps ≥ 80% of its tokens, ABSTAIN if any span keeps < 30%, otherwise dropped.

3

Train. Rank-16 LoRA (10.1M params, attention only) on frozen Qwen2.5-7B-Instruct: emit the gold answer on CONFIDENT, a fixed refusal on ABSTAIN.

Honest accuracy = answer correctly when the evidence survived + refuse when it was evicted. Both directions count, so over-refusing is penalized as much as hallucinating.

→Takeaway

Compressed models should know when they no longer know. A small adapter, trained on labels read off the compressor’s own survival mask, turns silent evidence loss into an explicit refusal.

Prompting refuses too much

On answerable questions at r = 0.80, the abstention prompt refuses 49–51%; the mixture adapter refuses 6–10%. Pooled over compressors, the adapter wins +32 pp there (McNemar 95 vs 13, p = 1.5×10−16).

8Limitations

  • Aggregate scores can be gamed: labels are U-shaped in r, so a rule on r alone reaches 0.93. We report per-ratio and per-class slices.
  • Span survival is a proxy for sufficiency: κ = 0.61 vs. an LLM judge (80% agreement).
  • Under compressed-cache decoding, answering at high retention is still hard (0.32 at r = 0.80).
  • MuSiQue 2-hop only; compressed-cache tests use KVzipPress only.
